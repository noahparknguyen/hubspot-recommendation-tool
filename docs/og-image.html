How to export: open this file in Chrome, wait a second for the fonts to load, then right-click a frame → Inspect → in the Elements panel right-click the highlighted <div class="frame …"> → Capture node screenshot. That saves the frame at its exact pixel size — no cropping. Save the 1200×630 frame as frontend/public/og-image.png (referenced by the meta tags in frontend/index.html). Save the 1280×640 frame as docs/preview.png — that file is the checked-in copy of the GitHub social preview, which has to be uploaded by hand under repo Settings → Social preview because GitHub stores it outside the repo.
